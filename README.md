# sparktime

Spark CSV/TSV time tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/sparktime/

## Install / run

```bash
git clone https://github.com/theworker02/sparktime.git
cd sparktime
node src/cli.js
node --test
```
